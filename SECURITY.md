# Security Policy

## Project Ethos
**jetio** is a volunteer-driven, open-source framework created to contribute to the developer community. We maintain this project in our free time to help others build better software.

While we strive to keep the framework secure, please understand that this project comes with **no warranties** and **no financial bug bounties**. We rely on the goodwill of the community to report issues responsibly so we can fix them for everyone's benefit.

## Supported Versions

We focus our limited resources on the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue, we ask that you report it privately first. This gives us a chance to patch it before it can be exploited, protecting the users who rely on this framework.

### How to Report
Please do not open public GitHub issues for security vulnerabilities.

1.  **Private Report:** Use the [GitHub Security Advisory](https://github.com/cehstephen/jetio/security/advisories/new) feature to start a private discussion.
2.  **Details:** Please include a brief description and a snippet of code (Proof of Concept) showing the issue.

### Our Response
As we are volunteers:
* We will try to acknowledge your report as soon as we are available.
* We will prioritize security fixes in the next release.
* **Attribution:** While we cannot offer payment, we are happy to publicly acknowledge your contribution in our release notes (if you wish) as a thank you for helping keep the ecosystem safe.
